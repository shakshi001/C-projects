Absolutely. If you're learning these sorting algorithms, here are **LeetCode problems that directly or indirectly build the skills behind each one**.

> Note: LeetCode rarely asks you to implement a textbook sort like “write Selection Sort.” Instead, problems test the **ideas behind sorting**—swapping, insertion, merging, partitioning, recursion, and using sorted order.

## 1\. Selection Sort

Best for practicing **finding minimum/maximum and placing it at the correct position**.

- **LeetCode 912 — Sort an Array** ⭐
- Implement sorting yourself.
- Excellent starting point for Selection/Bubble/Insertion Sort.
- **LeetCode 215 — Kth Largest Element in an Array**
- Useful for understanding selection and partitioning.
- **LeetCode 414 — Third Maximum Number**
- Practice finding top values without relying on built-in sorting.
- **LeetCode 75 — Sort Colors** ⭐
- Stronger problem involving in-place rearrangement.

**Recommended order:** `912 → 414 → 75 → 215`

---

## 2\. Bubble Sort

Bubble Sort teaches **repeated adjacent comparisons and swaps**.

- **LeetCode 912 — Sort an Array** ⭐
- Implement Bubble Sort yourself.
- **LeetCode 283 — Move Zeroes** ⭐
- Very good for understanding adjacent movement.
- **LeetCode 75 — Sort Colors**
- In-place swapping and partitioning.
- **LeetCode 147 — Insertion Sort List**
- Not Bubble Sort, but useful for comparing sorting approaches on linked lists.

### Practice challenge

Try solving **912** with:

1. Bubble Sort
2. Selection Sort
3. Insertion Sort
4. Merge Sort
5. Quick Sort

That single problem is excellent for understanding the differences.

---

## 3\. Insertion Sort

Insertion Sort is especially useful for learning how to **insert an element into an already sorted portion**.

- **LeetCode 147 — Insertion Sort List** ⭐⭐⭐
- This is the most direct LeetCode problem.
- Implement insertion sort on a linked list.
- **LeetCode 912 — Sort an Array**
- Implement array-based insertion sort.
- **LeetCode 57 — Insert Interval**
- Different problem, but reinforces the concept of inserting something into ordered data.
- **LeetCode 88 — Merge Sorted Array**
- Helps develop sorted-array manipulation skills.

**Must-do:** `147`

# 4\. Merge Sort

This is where LeetCode becomes particularly useful.

Merge Sort teaches:

- Divide and conquer
- Recursion
- Merging sorted arrays
- Counting inversions
- O(n log n) sorting

- **LeetCode 912 — Sort an Array** ⭐⭐⭐
- Implement Merge Sort.
- **LeetCode 88 — Merge Sorted Array** ⭐⭐⭐

- **LeetCode 23 — Merge k Sorted Lists** ⭐⭐⭐

- **LeetCode 148 — Sort List** ⭐⭐⭐

# 5\. Quick Sort

Quick Sort teaches:

- Partitioning
- Pivot selection
- Divide and conquer
- In-place rearrangement

### Good problems

- **LeetCode 912 — Sort an Array** ⭐⭐⭐
- Implement Quick Sort.
- **LeetCode 75 — Sort Colors** ⭐⭐⭐
- Very useful for partitioning.
- **LeetCode 215 — Kth Largest Element in an Array** ⭐⭐⭐
- Excellent introduction to **Quickselect**.
- **LeetCode 973 — K Closest Points to Origin** ⭐⭐
- Can be solved using Quickselect.
- **LeetCode 324 — Wiggle Sort II** ⭐⭐⭐

### Recommended progression


# 6\. Recursive Bubble Sort

LeetCode doesn't really have a problem specifically asking for **Recursive Bubble Sort**.

Instead, use:

- **LeetCode 912 — Sort an Array**
- Implement Bubble Sort recursively.
- **LeetCode 206 — Reverse Linked List** ⭐
- Great recursion practice.
- **LeetCode 203 — Remove Linked List Elements**
- Basic recursive thinking.
- **LeetCode 24 — Swap Nodes in Pairs**
- Helps with recursive swapping.
- **LeetCode 94 — Binary Tree Inorder Traversal**
- General recursion practice.

For Recursive Bubble Sort, the important pattern is:

```
Bubble one element to its final position
        ↓
Recursively sort the remaining n - 1 elements
```

---

# 7\. Recursive Insertion Sort

Again, LeetCode doesn't have a dedicated "Recursive Insertion Sort" problem.

But these are useful:

- **LeetCode 912 — Sort an Array** ⭐
- Implement recursive insertion sort.
- **LeetCode 147 — Insertion Sort List** ⭐⭐⭐
- Directly tests insertion-sort logic.
- **LeetCode 206 — Reverse Linked List**
- Strong recursion practice.
- **LeetCode 21 — Merge Two Sorted Lists**
- Helps with recursively processing sorted structures.
- **LeetCode 24 — Swap Nodes in Pairs**
- More recursion + pointer manipulation.

The recursive idea is:

```
Sort first n - 1 elements
        ↓
Insert element n into sorted portion
```
